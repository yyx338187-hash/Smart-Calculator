# Smart Calculator

## About
This is a simple calculator where you can run different calculations, the calculator includes error handling for several common invalid inputs, it is opened for testing and feedbacks.

## Features
-Division by zero handling
-Input validation
-Continuable calculation loop

## Status
ALPHA

## How to Run
Run it as any python programme, Python 3.x.x is required, windows terminal(cmd) is available but there are unintentional visual bugs. Pyfiglet is required to run the programme.
