# Smart Calculator

## About
This is a simple calculator where you can run different calculations, the calculator includes error handling for several common invalid inputs, it is opened for testing and feedbacks.

## Features
-Division by zero handling
-Input validation
-Repeated calculations without restarting the program
-Addition
-Subtraction
-Multiplication
-Division

## Status
ALPHA

## How to Run
Run it as any python program, Python 3.x.x is required, windows terminal(cmd) is available but there are unintentional visual bugs. Pyfiglet is required to run the program.
